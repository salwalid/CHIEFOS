Data Dictionary

Operational Assets

table_Asset_Registry
The master inventory for all physical and significant digital assets (e.g., properties, vehicles, server hardware). Tracks real-time status, maintenance cycles, and property-specific notes.
table_Asset_Utilities
Connects assets to their service infrastructure. Maps account numbers, vendor portals, and specific support contacts to the parent asset for rapid troubleshooting.
table_Contractor_Network
A vetted directory of external service providers. Includes historical ratings, specialty tags, and direct contact details for maintenance and mission-specific work.

Strategy & Execution

table_Tactical_Horizon
The centralized task-orchestration engine. Manages short-term tasks and long-term milestones, organized by priority, deadline, and hierarchical Mission IDs.
table_Social_Posts
A creative repository for high-leverage content. Stores hooks, final drafts, and scheduling metadata for social platforms (LinkedIn, Twitter) to ensure consistent strategic messaging.
table_Alpha_Blog_Posts
The content engine for [your-domain]. Tracks technical blog posts, draft status, and category tags. Cross-linked to tactical tasks for production and social posts for distribution.
table_Context_Vault
Long-term knowledge base for evolving concepts. Captures strategic breakthroughs, implementation links, and the Principal's current sentiment on project directions.
project_metadata
High-level project definitions. Tracks the lifecycle, status, and updated descriptions of active development and business initiatives.

Financial Intelligence

table_Financial_Ledger
Operational expense tracker. Records bills, payment status, and due dates linked directly to properties and assets for cash-flow visibility.
table_Recurring_Vulnerabilities
A specialized subscription and SaaS auditor. Monitors recurring costs for trend shifts, price increases, or redundant service "vulnerabilities."
table_Usage_Ledger
Real-time resource audit. Logs AI model interactions, token burn, and estimated session costs to manage the Alpha operational budget.

Governance & Security

table_Maat_Audit_Trail
The primary compliance log. Records every tiered action, the rationale for classification, and the Guardian's verdict to ensure MaatSpec alignment.
table_Perimeter_Logs
Security perimeter surveillance. Captures access events, IP metadata, and connection status to maintain system integrity.
agent_state_history
A granular activity log for sub-agents. Records the internal transitions and specific tool-calls of specialized agents (JS, Super, Agent-D).

System Intelligence

table_System_Agents
Master agent roster and coordination data. Stores agent identities, designated domains, models, and directory scopes for the Alpha orchestrator.
table_System_Tools
A structured catalog of all available system tools. Includes Tier classifications, descriptions, and restricted status for governance audits.
table_Alpha_Intel
Persistent key/value store for the Alpha kernel. Used for managing operational state across sessions (e.g., email sync checkpoints).
table_Alpha_Routines
Definitions for automated workflows. Stores the sequences, time windows, and requirements for recurring system tasks.
table_Alpha_Chronicles
Self-improvement and failure log. Records system component events, error logs, and "lessons learned" for future recursive optimization.
system_environment
Global environment variables. Stores core runtime configuration, descriptions, and update timestamps for the Alpha OS.
